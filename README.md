# DevOps Project
## Cel projektu
Nauka podstaw narzędzi DevOps w praktyce
## Opis
Projekt do nauki podstaw DevOps:
- Linux (zarządzanie plikami, uprawnienia)
- Git (commit, log, repozytorium)

## Technologie
- Linux (Ubuntu, VirtualBox)
- Git

## Co zrobiłem
- praca na plikach i katalogach
- użycie komend: ls, cd, grep, chmod
- zarządzanie repozytorium Git

## Jak uruchomić

```bash
chmod +x script.sh
./script.sh
```
